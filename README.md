# 🍽️ Red Table

A modern, responsive homepage for a restaurant serving family recipes and local ingredients.

🔗 **Live site:** https://theredtable.netlify.app/

## ✨ Features

- Mobile-friendly design
- Hero section with a background photo
- "Favorites from our kitchen" food cards
- Red and white theme

## 🛠️ Built with

- HTML
- Tailwind CSS
- Netlify
